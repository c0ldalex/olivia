# ALEAN SEA 🐬

Интерактивная браузерная игра с виртуальным дельфином.
Концепт-прототип гостевого сервиса для семейного отеля (Alean Family Olivia, Анапа).
**Не является официальным продуктом компании.**

## Что внутри

- Чистый HTML/CSS/JS, без сборки, серверов и баз данных.
- Прогресс хранится в `localStorage` (телефон ребёнка, без регистрации).
- Экспорт/импорт прогресса кодом — перенос на другое устройство.
- 4 мини-игры: викторина, аркада «Сбор сокровищ», эко-уборка, исследование локаций.
- 5 локаций, 4 стадии роста дельфина, ежедневные задания, 12 достижений, коллекция существ, 12 фактов о Чёрном море.

## Структура проекта

```
alean-sea/
├── index.html      # все экраны (SPA)
├── css/style.css   # стили, mobile-first
├── js/data.js      # факты, вопросы, локации, достижения — расширять здесь
└── js/game.js      # игровая логика, сохранения, мини-игры
```

## Запуск локально

Откройте `index.html` в браузере (двойной клик). Всё работает офлайн.

## Публикация на GitHub Pages

1. Создайте репозиторий на github.com, например `alean-sea`.
2. Загрузите файлы (корень репозитория = папка `alean-sea/`).
3. В репозитории: **Settings → Pages → Source: Deploy from a branch → Branch: main, / (root) → Save**.
4. Через 1–2 минуты сайт будет доступен по постоянной ссылке:
   `https://<ваш-ник>.github.io/alean-sea/`

## QR-код

1. Откройте любой генератор QR (например, `qrcode-monkey.com`).
2. Вставьте ссылку `https://<ваш-ник>.github.io/alean-sea/`.
3. Скачайте QR и разместите в номере/зоне отеля.

Один QR ведёт на стартовую страницу для всех гостей. Для персонализации по номерам
достаточно добавить параметр (например, `?zone=lobby`) — архитектура это допускает.

## Расширение

- Новые мини-игры: добавьте функцию `gameX()` в `js/game.js` и кнопку с `data-act="x"`.
- Новые факты/вопросы/существ: просто допишите массивы в `js/data.js`.
- Прогресс версионируется ключом `alean_sea_save_v1` — при изменении формата данных
  можно ввести `v2` с миграцией.
